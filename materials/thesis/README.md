# Thesis

Open topics are not here: each one is an **[issue](../../../../issues)** in this repository.

This folder holds the templates to write in. Use them from the start, not in the last month. They drop straight into [Overleaf](https://www.overleaf.com/) if you'd rather not install a TeX distribution.

| | For |
|---|---|
| [`thesis`](thesis) | BSc, MSc and PhD theses, with a [writing guide](thesis/README.md) explaining what goes in each chapter |
| [`lab-report`](lab-report) | lab and project reports |
| [`presentation`](presentation) | Beamer slides for your defence |
